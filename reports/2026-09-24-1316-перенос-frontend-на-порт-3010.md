# Перенос Frontend (dev.infomania.ru) с порта 3000 на 3010

**Дата:** 2026-09-24

## Цель
Освободить порт 3000 на сервере 192.168.0.35 (например, под установку Dokploy).

## Что было
- 192.168.0.35: pm2-процесс `Frontend` (id 1, Nuxt, `/home/admin_web/infomania-web/frontend/.output/server/index.mjs`) слушал порт 3000.
- nginx на 192.168.0.13 (`/etc/nginx/sites-available/default` ← `sites-enabled/infomania.conf`), блок `server_name dev.infomania.ru`, строка 285: `proxy_pass http://192.168.0.35:3000;`.

## Что сделано
1. На 192.168.0.35: `PORT=3010 pm2 restart Frontend --update-env`, затем `pm2 save`, чтобы порт сохранился после перезагрузки сервера.
2. На 192.168.0.13:
   - бэкап: `/etc/nginx/sites-available/default.bak_before_port3010_2026-09-24_131622`;
   - строка 285 заменена на `proxy_pass http://192.168.0.35:3010;`;
   - `nginx -t` прошёл, выполнен `systemctl reload nginx`.

## Проверка
- `curl http://127.0.0.1:3010/` на 35-м → 200.
- `curl -H "Host: dev.infomania.ru" http://127.0.0.1/` на nginx-сервере → 200.
- Порт 3000 на 35-м никто не слушает.

## Откат
```bash
# 192.168.0.13
sudo cp -p /etc/nginx/sites-available/default.bak_before_port3010_2026-09-24_131622 /etc/nginx/sites-available/default
sudo nginx -t && sudo systemctl reload nginx
# 192.168.0.35
PORT=3000 pm2 restart Frontend --update-env && pm2 save
```

## Замечания
- Если Frontend деплоится через CI (например, actions-runner в `~/actions-runner`) командой `pm2 start/restart` с явным `PORT=3000`, следующий деплой вернёт порт 3000. Нужно поправить workflow/ecosystem на 3010.
- Dokploy кроме 3000 занимает порты 80 и 443. На 35-м они сейчас свободны.
