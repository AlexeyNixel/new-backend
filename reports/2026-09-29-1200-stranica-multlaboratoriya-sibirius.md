# Страница «Мультлаборатория «Сибириус»» (блочный формат)

## Задача

По новостям сайта о «Мульт-Сибири» / мультлаборатории «Сибириус» собрать страницу проекта в новом блочном формате (`Page.blocks`).

## Что сделано

1. **Анализ новостей.** В таблице `posts` нашлось 118 неудалённых новостей со словами «Сибириус», «мультлаборатор», «Мульт-Сибирь» (2020–2026), из них 96 упоминают «Сибириус». Скрипт выгрузки — `temp/mult-search.ts`, выгрузка — `temp/mult-posts.json`.
2. **Факты из новостей:**
   - студия открылась осенью 2021 года при медиатеке НОМБ в рамках проекта «Мульт-Сибирь» (НРОО «Гильдия молодых библиотекарей», грант Президента РФ, 30.09.2021–31.10.2022). Вместе с ней открылась сеть мультстудий в Кочковском, Черепановском, Маслянинском, Карасукском районах и Куйбышеве;
   - руководитель — Бычкова Наталья Васильевна (главный библиотекарь медиатеки); педагоги-мультипликаторы — Скоробогатова Н. В. (координатор проектов), Кузьмина А. А.;
   - техника перекладки, мультстанок СПАФ-32М, Movavi; возраст 10–18 лет, занятия бесплатные, тел. 8 (383) 210-12-04;
   - второй грантовый проект — «Мульт-галерея Славы Новосибирской области» (ПФКИ, 24.10.2023–24.06.2024, 12 мультфильмов, более 2400 зрителей);
   - награды: «МультСемья» 2022/2023/2024 (Гран-при за «Крячкова»), «Золотое пёрышко» 2023, «Это всё моя Россия» 2023, «Дивный мир» 2024 (4 диплома I ст.), «Мультикадр» 2026 (лауреат I ст.).
3. **Страница создана в БД** (`pages`): slug `multlaboratoriya-sibirius`, id `5f160ee8-3a09-419e-97fc-213016b82df6`. Откроется на фронте по адресу `/page/multlaboratoriya-sibirius`.
   Блоки: `hero` → `stats` → `richText` (о проекте) → `features` (направления) → `advantages` (чему учат) → `tags` (фильмы) → `richText` (награды) → `highlight` (Мульт-галерея Славы) → `richText` (команда) → `person` (руководитель) → `richText` (17 ссылок на ключевые новости) → `banner`.
   Сборка — `temp/mult-page-build.js` → `temp/mult-page.json`, запись — `temp/mult-page-upsert.ts` (обновляет существующую запись по slug, можно запускать повторно).

## Решения и оговорки

- Подборку новостей сделал через `richText`, а не через `archive`: фронт `archive` рендерит, но в админке (`frontend-admin`, `PageBuilder`) этого типа нет, и `getPageBlockMeta('archive')` вернёт `undefined`, из-за чего редактор страницы упадёт. Типа `archive` нет и в бэкенде (`src/page/types/page-block.type.ts`).
- В компоненте `person` на фронте подпись «Руководитель отдела» зашита в код, поэтому должность («Руководитель мультлаборатории…») указана в поле `position`.
- Расписание групп (ср 10:00–12:00, чт 15:30–17:30) последний раз публиковалось в наборе на 2024/25 учебный год, поэтому на страницу его не выносил. Адрес (Красный проспект, 26) взят из новостей библиотеки.
- Картинок на странице нет, их можно добавить в админке через `richText`.
- Сайт в браузере не проверял: локальный API не запущен, запись проверена чтением из БД.
