# Анализ версии сервера MinIO (minio.infomania.ru)

## Что установлено
Получено через admin API (`GET /minio/admin/v3/info`, только чтение) на внутреннем адресе 192.168.0.41:10001:
- Версия: **RELEASE.2023-09-04T19-57-37Z** (commit 1c99fb10), около 3 лет.
- Режим: один узел, один диск (Erasure, 1 drive, parity 0), то есть без избыточности.
- Бакетов: 3, объектов: 104 556, объём ≈ 37 ГБ. Аптайм ≈ 62 дня.
- minio.infomania.ru — nginx, отдающий консоль, не S3 API. Его TLS-сертификат выдан только на `infomania.ru` (нет SAN `minio.infomania.ru`), поэтому браузер/curl ругаются.

## Состояние проекта MinIO
- Community Edition: в декабре 2025 переведена в maintenance mode, готовые бинарники/Docker-образы перестали выпускаться в октябре 2025, репозиторий архивирован (апрель 2026). Лицензия осталась AGPLv3.
- Последний официальный бинарный релиз — RELEASE.2025-10-15T17-29-55Z; дальнейшие исправления — только в исходниках.
- В 2025 году из community-консоли убрали админские функции (осталась только работа с объектами).
- Альтернативы: AIStor Free (коммерческий продукт MinIO, бесплатный для одного узла), форк pgsty/minio → Silo (AGPLv3, с бинарниками и консолью), Garage, SeaweedFS, RustFS и др.

## Уязвимости, затрагивающие 2023-09-04
- CVE-2024-24747 — повышение привилегий через service accounts (исправлено в 2024-01-31).
- CVE-2024-55949 — повышение привилегий через IAM Import API (исправлено в 2024-12-13).
- CVE-2025-31489 — обход проверки подписи при записи (исправлено в 2025-04-03).
- CVE-2025-62506 — обход session policy у service/STS аккаунтов (исправлено в 2025-10-15).
- CVE-2026-41145 — запись объектов без секретного ключа через streaming unsigned trailer (затрагивает версии от 2023-05-18, исправлено в 2026-04-11, только исходники).

## Вывод
Обновляться есть смысл, прежде всего из-за безопасности; функциональных выгод для бэкенда почти нет (используются только базовые S3-операции). Так как upstream закрыт, обновление стоит совмещать с выбором дальнейшей поставки (форк/AIStor/альтернатива). Объём (37 ГБ) позволяет переносить данные через `mc mirror`.
Сервер не изменялся.
