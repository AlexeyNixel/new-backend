# Игры одной серии не группировались (AZUL и похожие)

## Проблема

Несколько игр AZUL («AZUL», «AZUL. Витражи Синтры», «AZUL. Летний дворец»)
не отображались как одна серия.

## Диагностика

`extractSeriesBaseTitle` при миграции искал только двоеточие (`Дюна: ...`).
У части каталога подзаголовок отделён **точкой** («AZUL. Витражи Синтры»,
«Pathfinder. Бестиарий», «Ужас Аркхэма. Карточная игра: ...») или тире
(«Вся жизнь - игра»). Проверил на всех 668 играх — с точкой/тире
разделено ещё 10+ настоящих серий, которые эвристика полностью пропускала.

Второй пробел: базовая игра без подзаголовка («AZUL» без точки) не
присоединялась к своей же серии, даже когда её точное название совпадало
с базовой частью у остальных игр серии — именно это было в жалобе
пользователя (3 игры AZUL, ни одна не сгруппирована).

## Исправление

- `extract-series-base-title.utils.ts` — разделитель теперь: двоеточие,
  точка+пробел или тире/дефис с пробелами по бокам, берётся первый по
  тексту. Добавлена защита: если извлечённая база сама содержит точку
  (`т.д`, `V.I.P`) — считаем это аббревиатурой, а не серией, и не берём.
- Новая утилита `group-by-series.utils.ts` (`groupBySeriesTitle`) — общая
  логика группировки: сначала группирует по извлечённой базе, затем
  дополнительно подтягивает в группу игру, чьё **точное** название совпадает
  с базой уже найденной серии (это и есть случай «AZUL» без подзаголовка).
  Группы из одной игры отбрасываются.
- `GamesService.migrate()` переведён на `groupBySeriesTitle` (было —
  инлайновая копия той же логики, без подтяжки точного совпадения).
- Новый метод `GamesService.regroupSeries()` + `GET /games/regroup-series`
  (`JwtAuthGuard`) — пересчитывает серии для **всех** уже существующих игр
  (не только тех, что мигрируются заново): полностью снимает текущие
  `Game.seriesId`/`GameSeries` и строит заново по актуальной эвристике.
  Нужен, потому что `migrate()` группирует только то, что переносит сам, а
  668 игр уже были перенесены раньше со старой (только двоеточие) логикой.

## Проверка

- `npx jest` — 40/40 (добавлено 4 новых теста на разделители/аббревиатуры/
  подтяжку базовой игры + не создаём серию из одной игры).
- `tsc --noEmit`, `npm run build`, `eslint` — чисто.
- Прогнал `groupBySeriesTitle` на реальных 668 названиях — детерминированно
  даёт 64 серии / 203 игры (было 31 серию / 110 игр на старой логике).
  Выборочно проверил несколько новых серий на осмысленность (AZUL, DOOM,
  Ведьмак, Fallout, Находка для шпиона Spyfall, Крылья) — везде реальная
  база + её продолжение/переиздание, не мусор. Отдельно проверил, что
  «Fallout Shelter» (другая игра, просто созвучное название) **не** попала
  в серию «Fallout» — совпадение отсекается корректно.
- **Реально запустил `regroupSeries()`** на боевых данных (через
  `NestFactory.createApplicationContext`, тем же кодом, что и эндпоинт):
  `{ totalGames: 668, seriesCreated: 64, gamesGrouped: 203 }`. Проверил
  в БД — все 3 игры AZUL получили один и тот же `seriesId`.

## На заметку

`regroupSeries()` идемпотентен (полностью пересчитывает с нуля) — можно
перезапускать, если правится сама эвристика или добавляются новые игры
вручную через админку.
