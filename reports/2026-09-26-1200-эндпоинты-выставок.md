# Эндпоинты для выставок (File.type = EXHIBITION)

## Что сделано

Файлы с типом `EXHIBITION` теперь запрашиваются отдельно от остальных файлов:

- `GET /files/exhibitions` — список выставок с пагинацией (формат `ResponseService.paginated`).
  Query: `page` (1), `limit` (10), `search` (по `originalName`), `sortOrder` (`asc`/`desc` по `createdAt`, по умолчанию `desc`).
- `GET /files/exhibitions/:id` — одна выставка; 404, если нет файла с таким id или его тип не `EXHIBITION`.

Оба эндпоинта публичные (без `JwtAuthGuard`).

## Изменённые файлы

- `src/files/files.controller.ts` — два GET-эндпоинта.
- `src/files/files.service.ts` — `findAllExhibitions`, `findOneExhibition`.
- `src/files/files.module.ts` — в провайдеры добавлен `ResponseService`.
