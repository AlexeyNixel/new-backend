# Промпт для создания блочных страниц

## Задача

Пользователь попросил готовый промпт для создания новых страниц в блочном формате (`Page.blocks`).

## Что сделано

Промпт собран по типам блоков (`src/page/types/page-block.type.ts`), фронтовым компонентам (`frontend/app/components/page-blocks/`) и опыту прошлых страниц: «Сибириус», JAZZIUM, «НОМБ 50 лет», «Площадки», «Слушай Новосибирь».

В промпт вошли:
- список типов блоков и их полей;
- правила для `richText`: только инлайн-стили, сетки на `auto-fit`, картинки с `srcset`;
- загрузка картинок через `FilesService.uploadImage`, только чтение бакета `site`;
- проверки перед записью: существует ли slug, `blocks = null`, нет ли правок в журнале аудита;
- `content` не менять, чтобы откат был через `blocks = null`;
- проверка результата и отчёт.

Код не менялся. Сам промпт передан пользователю в чате.
