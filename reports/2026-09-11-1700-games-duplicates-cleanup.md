# Дубли игр (Цивилизация и ещё 21 штука)

## Проблема

Пользователь заметил дубль «Цивилизации» — некорректно отображается
(нет картинки, нет жанров).

## Диагностика

`"Цивилизация" Сида Мейера: Новый рассвет` существует в БД дважды:

| id | externalId | title | картинка | жанры | правила | описание |
|---|---|---|---|---|---|---|
| `8a110d3c…` | `gm28` | `"Цивилизация" Сида Мейера: Новый рассвет` | ✅ | 4 | ✅ PDF | ✅ |
| `07482257…` | `gl-136` | `"Цивилизация" Сида Мейера: Новый рассвет.` (точка в конце!) | ❌ | 0 | ❌ | текст с артефактами (обратные кавычки вместо нормальных) |

Причина — при миграции дедупликация `g_data` vs `gl_list` сравнивала
названия точным `trim().toLowerCase()`. Точка в конце строки у `gl-136`
не совпадает с оригиналом без точки → игра посчиталась «уникальной» и
перенеслась второй раз.

Проверил **все 668 игр** тем же способом (нормализованное сравнение без
пунктуации) — нашёл **22 такие пары**, не только Цивилизацию: Catan,
Comparity (×3), Каменный век, Каркассон, Кросмастер, Манчкин (×3), Мемо
(×3), Нет слов (у этой — даже тройной дубль: две одинаковые строки внутри
самого `gl_list` + оригинал), Рик и Морти, Таверна «Красный дракон»,
Шипучка, Это факт! (×3).

Во **всех 22 случаях без исключения** версия из `gl_list` хуже: 0 картинок,
0 жанров (у `gl_list` изначально нет медиа — выяснено ещё на этапе
проектирования модели), часто нет и описания. Версия из `g_data` — во всех
случаях полная. Критерий «какая отображается некорректно» — однозначный.

## Исправление

1. **Корень**: `migrate()` — дедупликация `g_data`/`gl_list` теперь сравнивает
   по `normalizeGameTitle()` (новая утилита, убирает кавычки/скобки/пунктуацию,
   схлопывает пробелы) вместо точного `trim().toLowerCase()`. TDD, 3 теста.
2. **Данные**: 22 найденных дубля из `gl_list` помечены `isDeleted: true`
   (мягкое удаление — как и everywhere в проекте). Не жёсткое удаление:
   строка с этим `externalId` остаётся в БД, поэтому повторный запуск
   `GET /games/migrate` не создаст дубль снова (идемпотентность по
   `externalId` не пострадала). Жёсткое удаление, наоборот, откатило бы
   исправление на следующем запуске миграции.

## Проверка

- `npx jest` — 43/43 (+3 новых теста на `normalizeGameTitle`).
- `tsc --noEmit`, `npm run build`, `eslint` — чисто.
- В БД: `"Цивилизация" Сида Мейера: Новый рассвет.` (с точкой) —
  `isDeleted=1`, оригинал без точки — активен. Активных игр стало 646
  (было 668, минус 22 дубля).
