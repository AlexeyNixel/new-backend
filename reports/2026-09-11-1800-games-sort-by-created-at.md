# Сортировка игр по дате добавления

## Задача

`GET /games` должен уметь сортировать «по дате добавления». Технически
`createdAt` уже сортируется (`orderBy: {[sortBy]: sortOrder}`), но
бесполезно: все 668 игр получили `createdAt` в момент миграции (в один и
тот же трёхчасовой интервал 10-11.09) — реальной даты добавления в
источнике нет. Попросили восстановить хоть какой-то порядок через старый
`externalId` — неточно, просто чтобы сортировка была осмысленной.

## Сделано

- `extractExternalIdSortNumber()` (`src/games/utils`) — достаёт число из
  хвоста старого id (`gm120` → 120, `gl-136` → 136, `393203` → 393203).
  TDD, 3 теста.
- `GamesService.backfillCreatedAtFromExternalId()` + `GET /games/backfill-created-at`
  (admin) — сортирует все игры **с** `externalId` по этому числу, проставляет
  каждой `createdAt` с шагом в минуту от базовой даты (2015-01-01). Игры
  **без** `externalId` (созданные вручную в админке) не трогает — у них уже
  настоящий `createdAt`.
- `GamesService.findAll()` — дефолт сортировки сменён с `title asc` на
  `createdAt desc` (новые сверху, как у постов).

## Проверка

- `jest` 46/46, `tsc`/`build`/`eslint` — чисто.
- Реально запустил `backfillCreatedAtFromExternalId()` на боевых данных:
  `{ total: 668 }`. Игра без `externalId` («Монополия Ванпис», добавлена
  через админку во время тестирования) не тронута — сохранила настоящую
  дату создания.
- `GET /games?limit=5` (без параметров сортировки — проверка дефолта):
  первой идёт «Монополия Ванпис» (реально самая свежая), дальше — игры в
  порядке, обратном их бэкфилленным датам.

## На заметку

Даты не настоящие — это стабильный, но условный порядок для сортировки,
не хронология. Если в источнике найдётся более точный сигнал (например,
`gl_list.date_include` для 74 игр оттуда) — можно уточнить `backfillCreatedAtFromExternalId`
отдельно, сейчас не делал (не просили).
